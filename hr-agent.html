업무규칙이유

자주 묻는 질문

 

확인 없이 바로 반영되나요?

입사일·생일 등록은 확인 없이 바로 진행합니다. 처리 후 생성된 일정과 노션 행을 보고하므로, 잘못된 경우 "방금 등록한 ○○ 일정 삭제해줘"라고 요청하면 됩니다.

같은 연차를 두 번 요청하면 중복으로 들어가나요?

아닙니다. 유급 휴가 사용 리스트에 같은 이름·날짜·구분이 이미 있으면 건너뜁니다.

이력서 ZIP 비밀번호는 어디에 저장되나요?

압축 해제에만 쓰고 노션이나 다른 곳에 기록하지 않습니다.

주민등록번호로 생일을 등록해도 되나요?

앞 6자리로 생년월일만 계산하고, 주민등록번호 자체는 캘린더·노션 어디에도 남기지 않습니다.

생일 일정이 캘린더에 안 보여요.

Google의 '생일' 전용 일정 유형은 연락처 캘린더가 아니면 화면에 표시되지 않아, 일반 종일 일정 + 매년 반복(RRULE:FREQ=YEARLY)으로 만듭니다. 기존에 다른 방식으로 만든 일정이 있다면 다시 등록해 주세요.
